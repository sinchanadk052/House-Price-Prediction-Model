# House Price Prediction Model

A machine learning regression pipeline designed to analyze housing dataset features and predict continuous house prices with high accuracy.

## Workflow Overview
1. **Exploratory Data Analysis (EDA)**: Correlation heatmaps, distribution plots, and outlier detection.
2. **Data Preprocessing**: Handling missing values, scaling continuous variables, and categorical encoding.
3. **Model Training**: Linear Regression, Ridge/Lasso regularization, and baseline comparisons.
4. **Evaluation**: Evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and \$R^2\$ Score.

## Tech Stack
- **Python 3.10+**
- **Scikit-Learn, Pandas, NumPy**
- **Matplotlib, Seaborn**
- **Jupyter Notebook**

## Getting Started
```bash
pip install -r requirements.txt
jupyter notebook House-Price-Prediction-Model.ipynb
```
